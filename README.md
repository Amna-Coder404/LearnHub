## ✦ What is LearnHub?

LearnHub brings essential student learning activities into one mobile experience. It connects with the LearnHub backend to display enrolled courses and lets students manage their assignments without switching between multiple screens.

## ✨ Features

| Feature | Description |
|---|---|
| 🔐 Authentication | Student login, OTP verification & password reset |
| 📚 My Courses | Access your enrolled courses |
| 📝 Assignments | View assignments, deadlines & marks |
| 📄 PDF Submission | Submit assignment files directly |
| 📊 Results | Check assignment results |
| 📡 Connectivity | Respond to internet connection changes |
| 💜 UI & Animation | Custom splash screen and modern interface |

## 🛠️ Built With

- **React Native** — Mobile UI
- **Expo SDK 57** — Development and builds
- **Expo Router** — File-based navigation
- **React Native Paper** — UI components
- **Moti** — Animations
- **AsyncStorage** — Local token storage
- **REST API** — Backend integration



## 🎯 The Goal

Make course access and assignment management simpler for students through a dedicated mobile experience.
